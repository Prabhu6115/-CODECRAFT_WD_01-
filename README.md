Interactive Navigation Menu

A fixed, responsive navigation menu built using HTML, CSS, and JavaScript. This menu remains visible as the user scrolls and includes dynamic style changes on scroll and hover for an enhanced user experience.

Features

Fixed position on all pages

Background color changes when scrolling

Smooth hover effects on menu items

Responsive and modern design


Technologies Used

HTML – for structuring the navigation and page content

CSS – for styling, hover effects, and transitions

JavaScript – for scroll detection and dynamic class changes


How to Use

1. Clone or download the repository

2. Open index.html in your browser

3. Scroll the page and hover over menu items to see the effects
